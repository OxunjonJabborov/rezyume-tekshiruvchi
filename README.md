# rezyume-tekshiruvchi
O'zbek tilida ishlaydigan Rezyume ni tanlagan ishingizga qanchalik mos kelishini tekshirib beradigan web-ilova.

## Muammo

Muammo uncha katta bo'lmagan narsa, lekin, buni avtomatlashtirilsa ancha vaqtni tejab qoladi.

## MVP chegarasi (nima kiradi va nima kirmaydi)

MVP da hozircha rezyume olinadi. U ma'lum qonun-qoidalar va ish talablari asosida tekshirilib chiqiladi. Natija rezyume qanchalik to'g'ri va ishga qanchalik mos kelishini foizlarda chiqaradi.d

## Tillar

Hozircha qo'llab-quvvatlanadigan til o'zbekcha

## Muvaffaqiyat mezonlari

0-33% - qoniqarsiz
33-66% - yaxshi
66-100% - a'lo
